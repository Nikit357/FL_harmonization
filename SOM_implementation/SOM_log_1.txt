
    PandoraRequesterV2 class for making requests to pandora via pandora API v2 or json dump

    All methods have temporary boolean argument old_format (default True).
    Old format means response like it was in old PandoraV1 based requester
        old format - {'id': 'Pharyngeal_Neoplasm', 'name': 'Pharyngeal_Neoplasm'}
        new format - {'uuid': '53f43f6c-c03e-4f21-901d-b356d672d0c7', 'termId': 'Pharyngeal_Neoplasm'}
    It is highly recommended to use new format!

    All methods can be parameterized via argumnent 'parameters' (dictionary)
    parameters keys and possible values:
        data_version: 'KB', LDT' (default 'KB')
        show_deprecated: 'ALL', 'NOT_DEPRECATED', 'ONLY_DEPRECATED' (default 'NOT_DEPRECATED')
        collect_parents: True, False (default False)
        include_synonyms: 'BG_ANNOTATION_ONLY', 'PRIMARILY_CONNECTED_SYNONYMS', 'ALL' (default 'BG_ANNOTATION_ONLY')
        search: serach items by name, label or synonym

    i.g. to get all LDT diagnoses with all synonyms in new format, use
    get_paginated_terms(
        endpoint='diagnoses',
        parameters={
            'data_version': 'LDT',
            'include_synonyms': 'ALL',
            'show_deprecated':'ALL'
        },
        old_format=False
    )
